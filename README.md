# ⚔️ VALKYRIE PROTOCOL: ZERO (XR Blocks Edition)

> **Tactical 3x3 Anime Cyberpunk Auto-Battler in WebXR**
> Developed with [XR Blocks](https://github.com/google/xrblocks) and Three.js.

---

## 🌟 Overview

**VALKYRIE PROTOCOL: ZERO** is an esports-grade tactical 3x3 auto-battler set in a cyberpunk anime universe. Commanders strategically position squads of Valkyries across front, mid, and back rows, draft dynamic synergistic buffs, and engage in real-time holographic auto-combat.

### Core Features

1. **Full Roster of 27 Valkyries across 3 Factions:**
   - **Neo-Valhalla** (VALK-01 to VALK-09): Fire, Ice, Shadow, Storm, and Divine Light.
   - **Abyssal Eden** (VALK-10 to VALK-18): Deep Ocean, Spores, Nanotech, and Tidal Sovereignty.
   - **Sol Dynasty** (VALK-19 to VALK-27): Solar Radiance, Imperial Gold, and Celestial Flash.

2. **3D Cyber Stadium Arena in WebXR:**
   - Holographic 3x3 Tactical Grid with interactive slots (Player vs Rival Commander).
   - High-definition 3D acrylic crystal Valkyrie figures with Faction Halos, floating Cyber Weapons, and ground neon bases.
   - Midfield laser divider, floating neon stadium pillars, and ambient energy field.

3. **3-Tier Cloth Damage & Climax Ultimates:**
   - **Tier 1 (Pristine):** Full sleek sci-fi armor plates.
   - **Tier 2 (Battle-Torn, <70% HP):** Cracked armor plating, exposed glowing cybernetics.
   - **Tier 3 (Climax Overdrive, <30% HP):** Shattered armor, radiant climax flame aura, and intense power surge.
   - **Climax Ultimate:** At 100 energy, Valkyries unleash their signature ultimate with full-spatial cut-in announcement banners and devastating AoE attacks.

4. **Dynamic Buff Draft System:**
   - Draft multi-depth tactical buffs before combat to enhance Vanguard attack, frontline defense, energy acceleration, or faction synergies.

5. **3D Valkyrie Studio / Inspector:**
   - Dedicated spatial inspector allowing commanders to view 3D figures, cycle through all 27 Valkyries, inspect stats and lore, and preview all 3 Cloth Damage tiers.

6. **Web Audio Synthesizer:**
   - High-tech procedural sound effects for clicks, placement, swap, blade slashes, laser beams, armor rip, and victory/defeat fanfares.

## 🚀 Running the Application

```bash
# Start development server on port 3000
npm run dev

# Build production bundle
npm run build
```

- **Desktop:** The built-in XR Blocks simulator provides keyboard and mouse simulation for complete testing.
